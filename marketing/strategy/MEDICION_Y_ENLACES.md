# Medición y enlaces

El destino comercial inicial propuesto es una conversación de demostración. Contar mensajes útiles y demostraciones realizadas, además de alcance y visualizaciones. El kit no instaló medición, píxeles, formularios ni automatizaciones.

| Etapa | Evidencia necesaria | Qué no demuestra |
|---|---|---|
| Exposición | Alcance/impresiones del panel de cada red | Que la persona leyó o quiere comprar |
| Interés | Guardado, respuesta relevante o clic confirmado | Que un mensaje preparado fue enviado |
| Conversación calificada | Registro comercial de un negocio con necesidad y permiso de contacto | Una venta |
| Demo agendada | Fecha aceptada y registrada | Asistencia |
| Demo realizada | Evidencia del encuentro y resultado | Suscripción pagada |
| Registro / checkout | Evento de la aplicación con consentimiento y definición revisados | Pago confirmado |
| Pago confirmado | Estado del servidor del proveedor y orden conciliada | Disponibilidad operativa completa si el alta falló |
| Cliente activado | Aprovisionamiento y acceso acreditados | Uso sostenido o renovación |

Registrar semanalmente por canal y pieza: alcance, visualizaciones, guardados, clics disponibles, conversaciones, conversaciones calificadas, demos agendadas y realizadas. Incluir denominador y periodo al calcular tasas. Los valores iniciales están vacíos, no se presentan datos de campaña ficticios. Revisar comentarios cualitativos. No prometer objetivos numéricos sin un piloto.

`strategy/metricas-semanales.csv` es una plantilla. `utm-links.csv` contiene propuestas, todas **inactivas** hasta validar el sitio público. No incluye correo, teléfono, nombre ni tokens. En Instagram/TikTok, no suponer que el enlace de cada publicación es clicable: usar enlace de perfil disponible o mensajes según cuenta. En YouTube Shorts tampoco depender del enlace escrito dentro del video.

La web ya define condiciones para analítica opcional: origen público canónico, ruta editorial sin query y consentimiento, entre otras. Las URLs UTM contienen query; el frente web debe definir cómo conservar atribución con consentimiento antes de activar. No remover UTM como parche, cambiar el consentimiento o activar píxeles desde marketing. Existe una dependencia de integración real, no una medición ya lista.

Prueba de enlaces antes de aprobar: HTTPS y dominio correctos; ruta y fragmento existentes; lectura móvil; CTA que corresponde a la disponibilidad del producto; contacto que recibe el mensaje; ausencia de sesión/tokens/PII; política y consentimiento aplicables; parámetros capturados sólo según contrato aceptado. No activar compra productiva hasta que el frente SaaS certifique el recorrido.

Los enlaces sociales son aportados por el propietario. Los intentos de consulta pública de esta entrega no devolvieron los perfiles completos; no se acreditan seguidores, verificación ni acceso de publicación. El dominio propio no se acreditó públicamente operativo en esta revisión. Por eso las piezas principales invitan a conocer el producto o conversar y los enlaces UTM permanecen pendientes.
