# Implementación de marca Cripton
Abra `galeria_marca.html` para comparar versiones y reducciones. Puede abrirse como archivo local; no usa un CDN ni descarga fuentes.

`brand.css` define tokens y tamaños iniciales. Inter es la familia de apoyo propuesta; si no está instalada se usa la familia de sistema. Los SVG del nombre no requieren fuente.

`manifest.example.webmanifest` es una muestra, no un manifiesto listo para cualquier despliegue. Ajustar rutas, alcance, inicio e integración del service worker. Los nombres y src dependen de la estructura del kit.

No se ha modificado el repositorio del POS. El prompt de Codex delimita esa tarea una vez aprobada la identidad.
